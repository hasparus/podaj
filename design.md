# zinc ledger

podaj is one dense column. one recipient key in the header. no environments list and no sidebar.

## copy

chrome is lowercase: podaj, key, value, add, create link, key file, share this once.

do not shout `PODAJ` or `KEY` in the interface. a placeholder may stay an env name such as `OPENAI_API_KEY`. that is a sample, not a label.

## icons

row actions use [pixelarticons](https://pixelarticons.com/mini/) via the `pixelarticons` package (24×24, drawn in `currentColor`):

- `eye` shows a value
- `eye-off` hides it
- `trash` removes the row

the accessible names stay lowercase: show, hide, remove.

show and hide render only when that row's value is non-empty. an empty row has remove only.
