# Terminal consume and one-shot semantics

- After browser **send**, the CLI receives readiness over its capability-authenticated WebSocket; only socket failure enables status polling. Status/navigation/GET/HEAD do not consume.
- Only `POST /api/handoffs/:id/consume` with that request's read Bearer capability collects ciphertext. The terminal validates transport recipient identity, decrypts in memory, and encrypts the entire received payload into a standard binary `.age` file. Network `PODAJ1.` is unchanged.
- Require exit 0 and stdout JSON shaped exactly as `{names: string[], file: absoluteAgeFilePath, identity?: localIdentityFilePath}`. For the default journey, `names` must contain `PODAJ_VERIFY_A`, `PODAJ_VERIFY_B`, and `deployment note` in received order; `file` must be an absolute existing path under scratch `${XDG_DATA_HOME}/podaj/inbox`, and `identity` the default scratch age identity path, never key contents. Prompts/URLs/instructions belong on stderr. No automatic plaintext values may appear in stdout, logs, files, or the global environment.
- Require a binary age receipt (not a `PODAJ1.` envelope or plaintext JSON), mode 0600, with private podaj/inbox directories 0700 and identity 0600. After `wait` exits, explicitly run `node "$REPO/dist/scripts/podaj.js" decrypt --identity "$IDENTITY" "$FILE"` in the same isolated environment. Parse stdout in memory and compare the complete payload exactly with `{"vars":[{"key":"PODAJ_VERIFY_A","value":"DUMMY-alpha"},{"key":"PODAJ_VERIFY_B","value":"DUMMY beta=with spaces & symbols"},{"key":"deployment note","value":"DUMMY-unexpected"}]}`. Do not filter to requested labels or save decrypted plaintext to a file. Share only comparison pass/fail, not plaintext output. A receipt must still preserve every field if requested labels are absent.
- Also check encrypted stdin with `node "$REPO/dist/scripts/podaj.js" decrypt --identity "$IDENTITY" <"$FILE"`. If native `age` is already available, compare `age --decrypt --identity "$IDENTITY" "$FILE"` in memory too; otherwise mark native-tool interoperability unverified rather than installing it. The bundled CLI needs no external age binary. Preserve explicit legacy standalone `PODAJ1.` decryption checks separately.
- Verify default identity reuse/no overwrite and override precedence as described in [cli-request.md](cli-request.md). The local age identity is intentionally unencrypted and owner-readable: it prevents accidental plaintext artifacts, not a compromised user/device. Receipt persistence after success is not crash or lost-response recovery; collection remains at most once.
- Inspect only the run's local SQLite if storage proof is needed: pending → ready ciphertext → consumed with ciphertext removed. No plaintext names/values, raw capabilities, owner token, or private key may be stored. Hashes/metadata are expected; do not publish a raw dump.
- A same-read-capability consume replay returns **410**. Atomic consume and the authenticated replay are proven by `test/worker-runtime.test.ts`; a random-token 401, random-ID check, or reopened fill page proves neither.
- Do not instrument the CLI to expose its hidden read capability for manual replay. Report runtime-test replay evidence separately from the compiled-CLI/browser journey.
- Fill is single-assignment: concurrent/repeated PUTs cannot overwrite/resurrect a handoff (409); only one concurrent consume wins. Runtime tests also prove cross-role/cross-slot rejection and native socket close/release.
- Default retention is 7200 seconds; private supported overrides are whole seconds 60–86400. Use existing expiry/runtime tests rather than sleeping for hours or changing the verification instance's protocol.
