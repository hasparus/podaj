# Security

podaj encrypts credentials in the browser and stores only `PODAJ1.` ciphertext in Cloudflare KV. Plaintext and private keys never touch the Worker.

## Cryptography

- **Content**: AES-256-GCM with a random 12-byte IV per handoff.
- **Key wrap**: RSA-OAEP with SHA-256 (4096-bit RSA keys generated by `npm run keygen`).
- **Wire format**: `PODAJ1.` + base64(JSON envelope with `iv`, `ciphertext`, `wrappedKey`, `env`, `v`).

## Worker hardening

- **Content-Security-Policy**: `default-src 'self'`; scripts and styles from same origin only; `connect-src 'self'`; `frame-ancestors 'none'`.
- **Origin check**: `POST /api/handoffs` rejects requests whose `Origin` header does not match the request URL origin (same-origin only; missing `Origin` allowed for same-origin navigations).
- **Size limits**: request bodies above `MAX_HANDOFF_BYTES` (default 32768) are rejected with `413`.
- **One-shot KV**: `GET /api/handoffs/:id` returns ciphertext once, then deletes the key; entries expire after 24 hours if unread.
- **ID format**: handoff IDs are 128-bit random hex; malformed IDs get `400`.

## Client

- Success and error feedback uses **`textContent` only** — no `innerHTML` on the success path (or elsewhere for user-controlled data).
- Decryption reads `private.pem` from a local file picker; the key is not uploaded.
- Only `PODAJ1.` ciphertext is accepted by the store API (no legacy `TAIENC1` / `ENVSEAL1` prefixes).

## Secrets in git

- **`private.pem` must never be committed.** Keys live under `~/.local/share/podaj/` (mode `0600` for private, `0700` for the directory).
- Deploy **`public.pem`** (or equivalent) via `public/environments.json` — public keys only.

## Operational notes

- Handoff URLs are capability URLs: anyone with the link can fetch the ciphertext once before expiry.
- Rotate RSA keys by updating `environments.json` and redeploying; old ciphertext cannot be decrypted with a new key pair.
- Set Cloudflare account secrets via Wrangler; do not embed API tokens in the repository.
